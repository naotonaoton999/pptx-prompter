プロンプター表示中の文字サイズ変更（Version 1.1以降）

PowerPointを操作している間でも、プロンプターが表示されていればキーボードショートカットで文字サイズを変更できます。

  • 拡大：Control + Option + Command + ↑（4pt大きくする）
  • 縮小：Control + Option + Command + ↓（4pt小さくする）

変更できる範囲は36〜88ptです。設定は管理画面にも反映され、保存されます。プロンプターが非表示の間はこれらのショートカットは無効です。表示／非表示の切り替えには、従来どおりCommand + Option + Pを使用できます。

自動スクロール（Version 1.2以降）

プロンプター表示中にControl + Option + Command + Sを押すと、自動スクロールを開始・一時停止・再開できます。速度は5段階（8／16／24／40／64 pt/秒）で調整できます。

  • 「スライド切替時に自動スクロールを開始」をONにすると、スライドを進めたときも戻したときも、新しいノートの先頭から自動でスクロールします。初期設定はOFFです。
  • リーディングガイドがOFFの場合、スクロールする余地のない短いノートでは移動しません。ガイドがONの場合は、短いノートでも最後の読み対象まで追従できるよう表示用余白を確保します。末尾では自然に停止します。
  • マウスホイールやトラックパッドで手動スクロールすると、自動スクロールは停止します。

Version 1.3：プロンプター表示直後の自動開始

  • 「スライド切替時に自動スクロールを開始」と「プロンプター表示直後に自動スクロールを開始」の両方をONにすると、スライドショー中の初回表示時に、現在のノートの先頭から自動開始できます。初期設定は両方OFFです。
  • 両方ONで自動スクロール中にプロンプターを一時的に隠し、再表示した場合は、同じ読み位置とスクロール位置から継続できます。
  • ショートカットやホイールで明示的に停止した場合は、単に再表示するだけでは自動再開しません。下段の設定を明示的にOFF→ONしてから再表示すると、新しい開始指示として扱われます。
  • 一時停止してガイドを動かしていない場合、Control + Option + Command + Sで同じ表示位置から再開します。最後まで到達して自然停止した後は、再表示だけでは勝手に再開しません。

リーディングガイド（Version 1.2以降）

現在の読み位置を背景色でハイライトします。管理画面から「行」「文章」「段落」の3つの単位を選べます。初期設定はOFFです。

  • ON／OFF：Control + Option + Command + R
  • 次の行・文章・段落：Control + Option + Command + →
  • 前の行・文章・段落：Control + Option + Command + ←

前後移動のショートカットは、プロンプターを表示し、リーディングガイドをONにしている間だけ有効です。自動スクロールと同時に使用すると、スクロール位置に応じてガイドが追従し、前後キーで読み位置を移しても自動スクロールを継続できます。末尾で自然停止した後は、前へ戻すと再開できる場合があります。一方、キーやホイールで明示的に停止した場合は、ガイドを移動しても勝手には再開しません。

自動追従はスクロール位置に基づく目安です。マイクで話した内容を認識する機能ではありません。

Version 1.3：ハイライト色・フォーカス・読み位置

  • ハイライト色：ブルー・グリーン・イエローから選べます。イエローでは文字が黒になり、読みやすさを保ちます。
  • フォーカス：OFF・弱・強から選べます。リーディングガイドONのとき、ハイライト以外の文字を暗く表示します。
  • 読み位置：「上部」「30%」「45%」から選べます。30%・45%は表示画面内の目安位置で、ノートの最初の文章から読み進めるよう動作します。
  • ガイドを前後の行・文章・段落へ手動移動すると、必要に応じて選択箇所が読み位置付近へスクロールします。自動スクロール中のガイド移動も継続可能です。
  • 新しいスライドへ切り替わると、そのスライドのノートの先頭から読み位置を設定します。

Automation権限について

PPTX PrompterがPowerPointの現在のスライド位置を取得するためには、macOSのAutomation権限が必要です。権限を拒否した場合は、システム設定の「プライバシーとセキュリティ」→「オートメーション」からPPTX PrompterによるMicrosoft PowerPointへのアクセスを許可してください。
