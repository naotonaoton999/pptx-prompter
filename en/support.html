Change font size during a presentation (Version 1.1 and later)

While the prompter is visible, you can adjust its font size with global keyboard shortcuts, even when PowerPoint is the active app.

  • Increase: Control + Option + Command + Up Arrow (4 pt per press)
  • Decrease: Control + Option + Command + Down Arrow (4 pt per press)

Font size is limited to 36–88 pt. Changes also appear in the main settings window and are saved. These shortcuts are inactive when the prompter is hidden. Use Command + Option + P to hide or restore the prompter.

Automatic scrolling (Version 1.2 and later)

While the prompter is visible, press Control + Option + Command + S to start, pause, or resume automatic scrolling. Choose from five speeds (8, 16, 24, 40, or 64 pt/second).

  • Enable “Start auto-scroll on slide change” to begin scrolling from the top of the new notes whenever you move to a different slide, forward or backward. This option is off by default.
  • Short notes may not need scrolling. Scrolling stops naturally when the end of the notes is reached.
  • Using the mouse wheel or trackpad to scroll manually stops auto-scroll.

Reading Guide (Version 1.2 and later)

The Reading Guide highlights the current reading position. In the control panel, choose the line, sentence, or paragraph mode. The guide is off by default.

  • Turn on/off: Control + Option + Command + R
  • Next line, sentence, or paragraph: Control + Option + Command + Right Arrow
  • Previous line, sentence, or paragraph: Control + Option + Command + Left Arrow

The previous/next shortcuts work only while the prompter is visible and the Reading Guide is enabled. When used with automatic scrolling, the highlight follows the approximate reading position, and you can jump forward or backward without stopping auto-scroll. After auto-scroll stops naturally at the end, moving the guide backward can allow scrolling to resume. Moving the guide does not automatically resume scrolling if you explicitly paused it or stopped it with manual scrolling.

Automatic following is estimated from the scroll position; it does not use speech recognition.

Automation permission

PPTX Prompter needs macOS Automation permission to read the current PowerPoint slide position. If you denied access, go to System Settings → Privacy & Security → Automation and allow PPTX Prompter to access Microsoft PowerPoint.
