PPTX Prompter Support

Thank you for using PPTX Prompter. For bug reports, questions or feature requests, contact us using the email address below.

Support email: pptxprompter999@ymail.ne.jp

Developer: Naoto Shirasu

What to include when contacting support

  • Your macOS version
  • Your Microsoft PowerPoint version
  • Your PPTX Prompter version
  • A description of the issue and steps to reproduce it
  • A screenshot, if available

Automation permission

PPTX Prompter needs macOS Automation permission to read the current PowerPoint slide position. If you denied access, go to System Settings → Privacy & Security → Automation and allow PPTX Prompter to access Microsoft PowerPoint.
