# PPTX Prompter GitHub Pages

App Store Connect用の公開サイト一式です。

## ファイル
- `index.html` — トップページ
- `privacy.html` — Privacy Policy URL用
- `support.html` — Support URL用

## 公開前に必ず変更する箇所
`support.html` の次の文字列を、実際のサポート用メールアドレスに置換してください。

```text
pptxprompter999@ymail.ne.jp
```

## GitHub Pagesでの公開例
リポジトリ直下へこの3つのHTMLファイルを配置し、GitHub Pagesを有効にすると、例えば次の形式になります。

- Top: `https://<username>.github.io/<repository>/`
- Privacy Policy: `https://<username>.github.io/<repository>/privacy.html`
- Support: `https://<username>.github.io/<repository>/support.html`

App Store Connectでは `privacy.html` をPrivacy Policy URL、`support.html` をSupport URLに使用してください。
